# worker_tracker
# 工作进度追踪器 - 收款管理版

一个功能强大的工作时间和收入追踪工具,专为自由职业者和按小时计费的工作者设计。

## 📱 在线使用

访问链接: https://fujzhang.github.io/worker_tracker/

> 💡 建议将此页面添加到手机主屏幕,像App一样使用!

---

## ✨ 主要功能

### 1️⃣ 工作记录管理
- 📅 记录每日工作时间(开始时间、结束时间)
- 💰 自动计算工作时长和收入
- 🌙 支持夜班加班费率设置
- 🎉 支持公共假日加班费率
- 📊 按日期分组显示历史记录
- ✅ 标记收款状态(已付/未付)

### 2️⃣ 收入统计
- 💵 实时显示总收入
- 📈 区分已收款和未收款金额
- 📋 支持一键复制每日工作汇总
- 🎯 智能计算平均日收入

### 3️⃣ 储蓄目标管理
- 🎁 设置购买目标和价格
- 📊 自动计算需要工作的天数
- 🏆 优先级排序功能
- ✨ 目标达成后自动扣除金额
- 🔄 支持退款功能

### 4️⃣ 个性化设置
- 👤 自定义用户名
- ⏰ 设置每日工作时长
- 💲 设置时薪
- 🌙 自定义夜班费率(晚上10点后)
- 🎊 自定义公共假日费率
- 📤 数据导出/导入功能

## 🚀 快速开始

### 第一次使用

1. **打开网页**  
   访问 `https://fujzhang.github.io/worker_tracker/`

2. **进行基础设置**  
   - 点击右上角 ⚙️ 设置按钮

   - 点击"添加工作记录"

## 📖 详细使用教程

### 记录工作时间

#### 基本记录
```
1. 日期: 选择工作日期(默认今天)
2. 开始时间: 例如 09:00
3. 结束时间: 例如 18:00
4. 点击"添加工作记录"
```

系统会自动计算:
- ⏱️ 工作时长(小时)
- 💰 应得收入
- 📊 更新总收入

#### 夜班/加班记录

如果你的工作包含夜班时段(晚上10点后):

1. **启用夜班费率**
   - 进入设置
   - 勾选"启用夜班/加班费率"
   - 设置夜班起始时间(默认 22:00)
   - 设置夜班费率(例如:1.5倍 = 150%)

2. **记录工作**
   - 正常输入开始和结束时间
   - 系统自动识别夜班时段
   - 自动应用加班费率

**示例:**
```
时薪: $100/小时
工作时间: 20:00 - 02:00 (共6小时)
夜班费率: 1.5倍
夜班起始: 22:00

计算:
- 20:00-22:00 (2小时) × $100 = $200
- 22:00-02:00 (4小时) × $150 = $600
- 总收入: $800
```

#### 公共假日记录

如果在公共假日工作:

1. 记录时勾选"公共假日"选项
2. 系统自动应用假日费率(默认2倍)
3. 可在设置中调整假日费率

---

### 管理收款状态

#### 标记已收款
```
1. 在历史记录中找到对应日期
2. 点击"标记已付"按钮
3. 该笔记录会移到"已收款"区域
```

#### 取消收款
```
1. 在"已收款历史"中找到记录
2. 点击"标记未付"按钮
3. 记录会回到待收款区域
```

#### 复制工作汇总

快速生成每日工作报告:

```
1. 点击任意日期的"📋 复制汇总"按钮
2. 自动复制格式化的工作信息
3. 可直接粘贴到聊天软件发送给客户
```

复制的内容格式:
```
📅 日期: 2025-11-03
⏰ 工作时长: 8.0 小时
💰 应得收入: $1,200
📝 备注: 正常工作日
```

---

### 设置储蓄目标

#### 添加目标

1. **打开目标面板**
   - 点击"储蓄目标"卡片中的"+ 添加目标"

2. **填写目标信息**
   - 🎯 目标名称: 例如"iPhone 15 Pro"
   - 💰 目标价格: 例如"8000"
   - 📝 描述: 选填,例如"256GB 黑色"

3. **保存目标**
   - 系统自动计算需要工作天数
   - 根据剩余可用金额和平均日收入计算

#### 管理目标优先级

```
目标会按优先级排序:
- 点击"↑"按钮: 提高优先级
- 点击"↓"按钮: 降低优先级
```

#### 确认购买

当达到目标金额后:

```
1. 点击"✅ 确认购买"按钮
2. 系统会:
   - 从可用余额中扣除金额
   - 将目标移到"已完成"区域
   - 更新可用余额
```

#### 退款功能

如果误操作或退货:

```
1. 在"已完成目标"中找到项目
2. 点击"↩️ 退款"按钮
3. 金额会返还到可用余额
4. 目标回到待购买列表
```

---

### 高级设置

#### 惩罚率设置

用于更精确的费率计算:

```
1. 进入设置 → 展开"惩罚率设置"
2. 启用夜班费率
   - 设置夜班起始时间
   - 设置费率倍数(例如:150% = 1.5倍)
3. 启用公共假日费率
   - 设置费率倍数(例如:200% = 2倍)
```

#### 数据导出

备份你的所有数据:

```
1. 进入设置
2. 点击"导出数据"按钮
3. 选择:
   - 💾 下载JSON文件: 保存到手机
   - 📋 复制到剪贴板: 粘贴到其他地方保存
```

导出的数据包含:
- ✅ 所有工作记录
- ✅ 所有储蓄目标
- ✅ 个人设置信息

#### 数据导入

恢复备份数据:

```
1. 进入设置
2. 点击"导入数据"按钮
3. 选择之前导出的JSON文件
4. 确认导入后,所有数据恢复
```

⚠️ **注意:** 导入会覆盖当前所有数据,请谨慎操作!

## 💾 数据存储说明

### 本地存储
- 所有数据保存在**你的浏览器本地**
- 不会上传到任何服务器
- 其他人无法看到你的数据
- **隐私安全** ✅

### 数据持久性
- 只要不清除浏览器数据,记录会一直保存
- 建议定期导出备份

### 跨设备同步
- 数据不会自动同步到其他设备
- 需要手动导出/导入来转移数据

## ❓ 常见问题

### Q: 数据会丢失吗?
A: 只要不清除浏览器数据,记录会一直保存。建议定期导出备份。

### Q: 可以在多个设备上使用吗?
A: 可以,但数据不会自动同步。需要通过导出/导入功能手动转移数据。

### Q: 为什么我的数据突然不见了?
A: 可能原因:
- 清除了浏览器缓存/数据
- 使用了无痕模式/隐私模式
- 更换了浏览器
解决方法: 如果有备份,可以通过导入功能恢复。

### Q: 可以修改历史记录吗?
A: 目前只能删除记录,不支持直接编辑。如需修改,请删除后重新添加。

### Q: 时薪可以随时修改吗?
A: 可以,但只影响新增的记录,不会修改历史记录。

### Q: 夜班费率如何计算?
A: 系统会将工作时段分为普通时段和夜班时段分别计算:
- 普通时段按正常时薪
- 夜班时段按设置的费率倍数计算
- 最后相加得出总收入

### Q: 可以设置多个不同的时薪吗?
A: 目前不支持。建议为不同项目分别计算,或使用加班费率功能。

### Q: 数据安全吗?会被别人看到吗?
A: 完全安全!所有数据只保存在你的设备浏览器中,不会上传到服务器,其他人无法访问。

```
每天结束时:
1. 查看当日收入
2. 点击"复制汇总"

```
