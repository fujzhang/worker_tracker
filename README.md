## 🚀 快速开始

### 第一次使用

1. **打开网页** 访问 `https://fujzhang.github.io/worker_tracker/`
2. **进行基础设置**

   - 点击右上角 ⚙️ 设置按钮
   - 填写你的姓名
   - 设置时薪（例如：24.95）
   - 设置每日工作时长（例如：8小时）
   - （可选）设置默认休息时间
   - 点击"保存所有设置"
3. **创建收入周期**

   - 在设置中找到"收入周期管理"
   - 点击"+ 添加周期"
   - 输入周期名称（如：第一期）
   - 选择起始和结束日期
   - 点击保存
4. **开始记录工作**

   - 选择日期（默认今天）
   - 输入开始时间（例如：09:00）
   - 输入结束时间（例如：18:00）
   - 如有休息时间，勾选"休息时间"并设置时段
   - 点击"添加工作记录"

## 📖 详细使用教程

### 记录工作时间

#### 基本记录

```
1. 日期: 选择工作日期（默认今天）
2. 开始时间: 例如 09:00
3. 结束时间: 例如 18:00
4. 点击"添加工作记录"
```

系统会自动计算：

- ⏱️ 工作时长（小时）
- 💰 应得收入
- 📊 更新总收入

#### 🆕 休息时间功能

如果工作期间有休息（如午休）：

1. **勾选"休息时间"复选框**
2. **设置休息时段**
   - 休息开始时间（例如：12:00）
   - 休息结束时间（例如：13:00）
3. **自动计算**
   - 系统自动从工作时长中扣除休息时间
   - 结束时间会自动调整，确保达到设定的日工时

**示例：**

```
每日工时设置: 8小时
工作时间: 09:00 - 18:00 (总共9小时)
休息时间: 12:00 - 13:00 (1小时)

实际工作时长: 9小时 - 1小时 = 8小时 ✓
```

**设置默认休息时间：**

```
1. 进入设置
2. 找到"默认休息时间"
3. 勾选"启用默认休息时间"
4. 设置默认的休息时段
5. 保存后，新增记录会自动应用默认休息时间
```

#### 夜班/加班记录

如果你的工作包含夜班时段（晚上10点后）：

1. **启用夜班费率**

   - 进入设置
   - 勾选"启用夜班/加班费率"
   - 设置夜班起始时间（默认 22:00）
   - 设置夜班费率（例如：1.5倍 = 150%）
2. **记录工作**

   - 正常输入开始和结束时间
   - 系统自动识别夜班时段
   - 自动应用加班费率

**示例：**

```
时薪: $100/小时
工作时间: 20:00 - 02:00 (共6小时)
夜班费率: 1.5倍
夜班起始: 22:00

计算:
- 20:00-22:00 (2小时) × $100 = $200
- 22:00-02:00 (4小时) × $150 = $600
- 总收入: $800
```

#### 公共假日记录

如果在公共假日工作：

1. 记录时勾选"公共假日"选项
2. 系统自动应用假日费率（默认2倍）
3. 可在设置中调整假日费率

#### 创建收入周期

```
1. 进入设置
2. 找到"收入周期管理"部分
3. 点击"+ 添加周期"按钮
4. 填写周期信息：
   - 周期名称：例如"第一期"、"11月工资"
```

```
- 点击周期旁边的"编辑"按钮可修改周期信息
- 点击"删除"按钮可删除周期
```

### 🆕 三种查看模式

#### 1. 当前模式 🔵

显示从上次收款之后到现在的所有工作记录：

```
- 用途：查看当前待收款的工作记录
- 显示：上次收款后的所有记录
```

**上次未结清提示：**

查看所有历史记录的总统计：

```
- 用途：全局数据分析
```

### 复制工作汇总

快速生成每日工作报告：

### 设置储蓄目标

#### 添加目标

1. **打开目标面板**

   - 点击"储蓄目标"卡片中的"+ 添加目标"
2. **填写目标信息**

   - 🎯 目标名称: 例如"iPhone 15 Pro"
   - 💰 目标价格: 例如"8000"
   - 📝 描述: 选填，例如"256GB 黑色"
3. **保存目标**

   - 系统自动计算需要工作天数
   - 根据剩余可用金额和平均日收入计算

#### 管理目标优先级

```
目标会按优先级排序：
- 点击"↑"按钮: 提高优先级
- 点击"↓"按钮: 降低优先级
- 只有第一优先级的目标达成后可以确认购买
```

#### 确认购买

当达到目标金额后：

```
1. 点击"✅ 确认购买"按钮
2. 系统会：
   - 从可用余额中扣除金额
   - 将目标移到"已完成"区域
   - 更新可用余额
```

#### 退款功能

如果误操作或退货：

```
1. 在"已完成目标"中找到项目
2. 点击"↩️ 退款"按钮
3. 金额会返还到可用余额
4. 目标回到待购买列表
```

## ❓ 常见问题

### Q: 休息时间如何计算？

A: 休息时间会自动从工作时长中扣除。例如：

- 工作时间：09:00-18:00（9小时）
- 休息时间：12:00-13:00（1小时）
- 实际工作时长：8小时

### Q: 为什么结束时间会自动变化？

A: 当你设置了休息时间后，系统会自动调整结束时间，确保达到你设定的每日工作时长。这样可以保证工作时长的准确性。

### Q: 如何查看上次少收的钱？

A: 切换到"当前"查看模式，如果上次收款时有少收的金额，会在顶部显示醒目的黄色提示框，包含周期信息和少收金额。

### Q: 收入周期可以重叠吗？

A: 可以，系统支持创建任意时间范围的周期。但建议周期不要重叠，以便准确统计每个周期的收入。

### Q: 数据会丢失吗？

A: 只要不清除浏览器数据，记录会一直保存。建议定期导出备份。

### Q: 可以在多个设备上使用吗？

A: 可以，但数据不会自动同步。需要通过导出/导入功能手动转移数据。

### Q: 可以修改历史记录吗？

A: 目前只能删除记录，不支持直接编辑。如需修改，请删除后重新添加。

### Q: 时薪可以随时修改吗？

A: 可以，但只影响新增的记录，不会修改历史记录。

### Q: 夜班费率如何计算？

A: 系统会将工作时段分为普通时段和夜班时段分别计算：

- 普通时段按正常时薪
- 夜班时段按设置的费率倍数计算
- 最后相加得出总收入

### Q: 数据安全吗？会被别人看到吗？

A: 完全安全！所有数据只保存在你的设备浏览器中，不会上传到服务器，其他人无法访问。
